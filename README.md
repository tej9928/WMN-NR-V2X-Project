NR-V2X Sidelink Performance Evaluation
This project explores the performance of NR-V2X Mode 2 (autonomous resource selection) using ns-3 and the 5G-LENA extension. It investigates how vehicles autonomously share radio resources without base-station assistance in a highway scenario and analyzes the trade-offs between communication reliability, vehicle density, resource selection algorithms, and retransmission strategies.

Key Research Objectives:

1) Vehicle Density Impact: Evaluate how increasing vehicle density affects reception reliability over the PC5 interface.

2) Resource Selection Mechanisms: Compare the performance of sensing-based resource selection against random selection.

3) Redundancy vs. Interference: Investigate whether blind retransmissions improve message delivery or increase channel congestion under heavy loads.
